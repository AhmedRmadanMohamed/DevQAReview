## Documentation conventions

- Keep screenshot filenames lowercase, descriptive, and separated with hyphens.
- Link to repository assets with relative paths so the documentation works on branches and in clones.
- Add descriptive alt text to embedded images.
- Identify the sample project and capture context when presenting metrics.
- Update the README and showcase captions together when replacing a screenshot.
- Keep future concepts and mockups clearly separate from captures of the current product.
