# DevQA Showcase Guide

## Product Identity

DevQA is an IntelliJ IDEA plugin focused on Spring Boot project intelligence and engineering quality awareness.

## Showcase Structure

The public repository is organized as a product showcase:

- `README.md` — Product overview and roadmap
- `docs/` — Documentation material
- `screenshots/` — Future dashboard screenshots
- `assets/` — Future branding assets

## Demo Presentation Flow

1. Open a Spring Boot project
2. Run DevQA Project Brain analysis
3. Discover project structure
4. Review detected components
5. Explore future quality intelligence features
