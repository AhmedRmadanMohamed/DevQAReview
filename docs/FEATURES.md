# DevQA Feature Showcase

## Project Brain (Current)

The first DevQA intelligence module focuses on repository understanding inside IntelliJ IDEA.

### Current Analysis Capabilities

- Spring Boot project detection
- Repository structure discovery
- Java class inventory
- Spring component classification
- Controller detection
- Service detection
- Repository detection
- Entity detection
- DTO detection
- Resource and configuration file discovery
- Interactive analysis dashboard

## Product Vision

DevQA aims to become an engineering intelligence platform that helps developers improve quality before code reaches QA.

## Future Intelligence Modules

- Architecture Intelligence
- Dependency Intelligence
- Security Analysis
- Testing Intelligence
- Code Quality Analysis
- AI Recommendations
- Project Health Scoring
